# FlowHub 测试验收清单

版本：`v0.1.0`  
更新时间：`2026-03-15`

## 1. 验收目标

本清单用于确认本次交付是否满足最小可用闭环。

重点不是“所有未来能力都完成”，而是确认以下主链路可以成立：

- Skill 索引可同步
- 自然语言命令可生成 workflow
- 用户可在对话中看到 Skill 说明和确认提示
- 用户确认后 request 可进入待执行状态
- Client 可回传 telemetry

## 3. Skill 索引验收

### 3.1 手动同步可用

验收方法：

```bash
cd backend
python scripts/sync_clawhub_skills.py
```

通过标准：

- 不报本地代码错误
- 同步结果能够写入 `skills` 表

### 3.2 API 触发可用

验收方法：

```bash
curl -X POST \
  -H "X-API-Key: dev-flowhub-key" \
  "http://127.0.0.1:8000/api/v1/skills/sync/clawhub"
```

通过标准：

- 返回同步结果 JSON

注意：

- 若上游限流，则可能因外部服务返回 429，这不直接判定本地代码失败

## 4. Planner 验收

### 4.1 自然语言转工作流

验收方法：

```bash
curl -X POST \
  -H "Content-Type: application/json" \
  -H "X-API-Key: dev-flowhub-key" \
  http://127.0.0.1:8000/api/v1/run-requests/ \
  -d '{
    "goal": "抓取 incident API 的最新状态并输出 markdown 简报",
    "targets": [{"type": "api", "label": "Incident API", "value": "https://example.com/api/incidents/latest"}],
    "credentials": [],
    "output_format": "markdown",
    "execution_mode": "remote",
    "user_notes": "面向客户沟通"
  }'
```

通过标准：

- 返回 `workflow_spec`
- 返回 `assistant_response`
- 返回 `selected_skills`
- 返回 `communication_preview`
- `workflow_spec.workflow_id` 已生成

## 9. 当前已知限制

### 9.1 ClawHub 上游限流

风险：

- 全量同步可能遇到 `429 Too Many Requests`

影响：

- 真实全量首轮导入可能受外部配额影响

### 9.2 AI 模型依赖外部配置

风险：

- 未配置模型密钥时，AI 规划不会启用

影响：

- 系统将自动回退本地规则，但不会中断主流程

### 9.3 WSL / Windows 网络差异

风险：

- OpenClaw / Node 运行在 Windows，后端运行在 WSL 时，`127.0.0.1` 可能不可达

影响：

- 插件联调需要改用 WSL IP

## 10. 验收结论模板

可直接用于交付确认：

> 经验证，FlowHub 当前版本已完成 Skill 索引、自然语言规划、用户确认、OpenClaw 对话桥接、客户端抓取执行与 telemetry 回传等核心链路，具备最小可用交付条件。当前已知限制主要集中在外部 AI 生产配置、ClawHub 上游限流和正式生产环境运维，不影响本次基础链路验收。
