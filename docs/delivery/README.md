# FlowHub 交付文档

版本：`v0.1.0`  
更新时间：`2026-03-15`

## 1. 文档用途

本目录用于项目交付，不是开发过程中的零散说明。

目标是让接收方能够快速理解：

- 这个项目是做什么的
- 当前已经交付了什么
- 如何启动、部署和联调
- 如何把它接入 OpenClaw 对话入口
- 当前哪些能力已经可用，哪些仍是边界项

## 4. 当前交付范围

本次可交付内容包括：

- FlowHub 后端 API
- 本地 Skill 索引与 ClawHub 同步能力
- 自然语言命令转工作流能力
- Run Request 创建与确认链路
- OpenClaw 对话插件桥接
- 前端内部调试页面
- Client Runtime 官方 Registry 抓取、客户端 AI 执行与 telemetry 回传

## 5. 当前不在本次交付闭环内

以下内容不作为“已完成生产交付”承诺：

- 外部 AI 模型生产环境账号与计费体系
- Client 安装包的签名、灰度分发与正式发布体系
- 真实生产调度与多租户权限体系
- OpenClaw 线上正式实例运维
